C2PA evidence viewer

This page shows real c2patool results recorded on this Mac. For each file it answers one question: does the file carry a C2PA Content Credential that is intact for these exact bytes, who signed it, and does the signer chain to a trust list we configured? It also says what stays unknown.

Precomputed, local-only results. Every result on this page was recorded in advance by running c2patool on this Mac, offline, in a network-denied sandbox. Your browser runs no validator; it only displays the recorded results. The page has no upload feature and loads nothing from the network.
  • Nothing here says whether an image is real or fake, and nothing here is an AI-probability score.
  • "Trusted" from c2patool means only that the signer chains to the public C2PA test root shipped with c2patool. Its private key is public, so this is never production trust.
  • Declared claims, such as a "digitalCapture" source type, are the signer's statements, not proven origin.
  • A missing credential is not evidence either way.
  • Production trust and certificate revocation were not evaluated for any case.
