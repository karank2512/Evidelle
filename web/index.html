C2PA evidence check

Pick a JPEG, PNG or WebP image. This page checks whether it carries a C2PA Content Credential that is intact for these exact bytes, who signed it, and whether the signer chains to one of the pinned C2PA trust lists. It also says what stays unknown.

  • This tool does not say whether an image is real or fake, and it is not an AI-probability score.
  • Trusted means the signer chains to the official C2PA conformance trust list, or to the frozen CAI interim list that the C2PA Verify site uses — both pinned in this app with source and SHA-256 in the evidence section. It never means a claim is true.
  • Declared claims, such as “captured by a camera”, are the signer’s statements, not proven origin.
  • A missing credential is not evidence either way: many tools never add one and some platforms strip them.
  • Certificate revocation status and remote (cloud) manifests are not fetched.
  • An optional experimental check can score the image with an AI-image detector (one-time ~60 MB download from this site). It is a probability score, not a verdict, and it is wrong often enough to say so plainly.
Everything happens on this device. The file is read by your browser and verified locally by the pinned C2PA WebAssembly verifier. There is no upload and no analytics: this page declares connect-src 'self', so it can only fetch this site's own files — your image is never sent anywhere. Airplane mode works after the first visit.
